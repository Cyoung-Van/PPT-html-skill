# 可观察验收

1. 离线打开正式 HTML，字体、图片、脚本与样式不依赖远程请求；外部引用链接除外。
2. 检查每页最终画面，真实文字/图表边界不溢出，正文、速览、导航不重叠，不能只检查空容器。
3. 在关键过渡约 100ms、中段和结束后观察主题进场、出现顺序与关系动画；仅有 animation 声明不算动效已验证。
4. 快速前后切换、目录/hash/附录跳转后只有一个活动页，旧动画不复活，片段状态一致。
5. 目录和讲稿可用键盘关闭并还原焦点；隐藏页不能获得焦点；输入框中打字不翻页。
6. 系统及手动减少运动停止循环与大幅变换，重要信息完整；后台、目录、讲稿状态暂停持续运动。
7. 六风格具有不同构图与运动方式，一套布局只换色或全稿同一淡入不算完成风格设计。
8. PDF 实际页数等于物理页数，分步和数值处于最终状态，水印与来源保留。成功退出码或文本抽取不能代替渲染检查。

check_deck.mjs 逐页测量和截图，记录运动中的动画数、快速跳转后的活动状态、减少运动后的运行数，输出 report.json 和中间帧/最终帧。仍需目视检查背景噪声、遮挡、图表标签、节奏和风格忠实度。失败时按具体边界修复，不无差别缩小全稿。

用 pypdf/pdfinfo 读 PDF 页数与尺寸，用 Poppler 渲染缩略图和代表页。透明图层水印可能不可抽取成文字，不能以抽不到文本判定水印缺失。

已通过检查不反复执行，除非新增修改、失败或有明确未解决问题。报告实际验证范围，不能把“提供模板脚本”说成“所有未来稿件的动效都已保证”。
