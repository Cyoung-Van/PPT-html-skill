# 从内容到可播放演示

## 现有稿件

读取实际 HTML 的标题、修改时间、页面结构和生成入口。生成器可能加载额外修订模块，不能只改基础 JSON/CSS 就认为正式稿同步。理清 HTML、内容源、样式、引擎和导出之间的关系。

备份后编辑。若 HTML 含手工修订，做限定补丁，不未经核对整稿重建。验证修改范围之外的正文、数字、引用和导航未变。导出显式接收当前输入路径，不记忆旧文件名。

## 新稿

按真实材料重写页序和正文。每页明确一个阅读任务，再安排标题、主视觉、证据和速览。研究/工程资料保留实测、模型、引用、假设、方案和未知的区别。示意图及动画终值不冒充实验结果。

先制作封面和最难正文，实播确认密度和节奏，再扩展全稿。这个判断步骤不意味着每次都停下来索要批准；用户要求直接完成时继续推进，明确“先给我看”时才只更新预览副本。

## 项目结构

    deck.json                 内容、稳定 ID、标签和可选路线
    assets/base.css           阅读区域、导航和打印
    assets/themes.css         六种风格
    assets/custom.css         本稿微调
    assets/decor.json          原生装饰 SVG / HTML
    assets/fonts/             原始字体与许可
    assets/templates/         技能中的六套独立场景（项目中用 deck.json）
    assets/engine.js           导航、动效和可访问性
    scripts/                  构建、检查、PDF 导出
    index.html                可独立复制的离线文件

CSS url() 和图片路径相对于项目根目录。本地图片和字体由构建器内联，外部参考链接可保留，演示加载不依赖网络。大型视频按实际交付介质选择本地附件并说明如何一同移动；基础生成器主要面向静态图片和轻量资源。

六套起始样例已使用本地字体文件，构建时生成当前文字的 WOFF2 子集并内联。新增文字需重新构建，不直接编辑字体子集。使用 fonts 配置中的 subset:true 启用这个流程。字体须确认真实族名、字重与所用字符覆盖，并检查浏览器实际加载。仅写字体名而系统回退，不算字体实现。使用用户提供或已获授权文件，保留许可；字体子集新增文字后须重建。

品牌使用确认原图和原比例，不能重绘校徽细节。水印默认关闭；简单内置水印是单文本字体，需要中英文分别设字时拆 span 并明确指定。不能默认把 NUAA、姓名或项目标志复制到未来新稿。

## 讲述与运动

先出现页面主题，再用方向、连接、描边、计数或层级展开表达关系。装饰循环应缓慢、局部、可暂停，正文、脚注和操作入口不跟背景漂移。六风格共用导航状态机，在场景与主题规则中实现区别，不改变前后页语义。

## PDF

导出前确认文件存在、不是错误页、字体与图片已加载、物理页数可得。打印显示全部片段、关闭动画、保存计数终值与页内水印。脚本的 expectedPages 是 HTML 数量，不是实际 PDF 页数验证。

使用 PDF 工具读取实际页数/尺寸，渲染所有页缩略图，放大封面、最密正文、深色页、末页。检查边框、页码、长速览、图表、来源、水印。旧 PDF 保留，动效以 HTML 实播验收。

项目微调虽最后加载，仍须遵守 CSS 选择器优先级。例如主题规则以 #stage[data-style="art-nouveau"] 开头时，用相同前缀加本页类名覆盖，不以一条更弱的 .quote 规则假定已生效。
