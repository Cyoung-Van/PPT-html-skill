# 动效设计与验收

## 动效是一份场景计划

每页先写一句观众应该理解的变化，再设计动画。对复杂页保留简短 `sceneMotion` 记录：

```json
{
  "intent": "先看输入，再看响应，最后确认结论",
  "beats": [
    {"at": 0, "target": "heading", "action": "establish"},
    {"at": 180, "target": "input", "action": "reveal"},
    {"at": 360, "target": "response", "action": "draw"},
    {"at": 720, "target": "takeaway", "action": "settle"}
  ],
  "trigger": "enter",
  "ambient": "none",
  "reducedMotion": "automatic motion settles immediately; manual steps remain user-controlled",
  "print": "all evidence and takeaway visible"
}
```

这里的时间单位为毫秒，是创作说明，不是引擎自动执行的通用脚本。基础引擎按风格执行换页和 `.reveal`；需要精确时间线时，为该场景明确实现局部动画并纳入同一取消/暂停管理。不要写了计划却没有可运行效果。

至少包含：① 页间转场；② 页内信息出现顺序；③ 操作反馈。背景循环可选，不能用背景漂浮代替前两项。自动播放、声音、自动翻页仅在用户要求时加入。

## 六种运动语法

| 风格 | 开场 / 换页 | 页内组织 | 常用时长与幅度 | 静止的部分 |
|---|---|---|---|---|
| Swiss | 水平推进，边界清晰，反向浏览方向反转 | 标题→数据→结论，按网格对齐的错峰进入 | 420–650ms；24–56px；错峰 65–100ms | 数据尺度、导航、正文最终位置 |
| Art Nouveau | 沿弧线舒展或轻微纵向接续 | 主茎描线→图像→说明，植物轮廓收束 | 650–850ms；18–40px；潮线 16–24s、≤12px | 正文基线、阅读区、按钮 |
| Art Deco | 从中轴展开或对称揭幕 | 细线建立→主题→成对信息 | 550–750ms；缩放约 .97→1；线框 400–600ms | 文字、主轴、信息对齐 |
| Memphis | 短促错拍，轻微一次回弹 | 先建立主形状，再按有意的顺序出现内容 | 350–500ms；20–45px；旋转通常≤3° | 正文、标题最终状态、导航 |
| Skeuomorphism | 面板进入与机械到位，不使用爆炸式飞散 | 电源→刻度/标签→读数；先确认输入再展示输出 | 400–800ms；按钮 80–180ms；指针一次阻尼 | 单位、刻度、警告、操作入口 |
| Psychedelic | 柔和景深/形变，背景与前景分层 | 短标题展开→稳定内容框→边缘场缓动 | 650–900ms；位移≤2%；背景 18–30s | 正文、导航、视频框、数据图 |

上述值是起点，不是为了满足数字而加动画。普通页的第一次信息可读时间尽量在 250ms 内，主体就位通常不超过 1 秒。正文至少保留一个稳定终态，不让观众追着文字阅读。

## DOM 与状态约定

- `.reveal`：进入当前页时按语义顺序揭示的块；避免给每个汉字拆 span。
- `[data-step="1"]`、`[data-step="2"]`：由下一步操作推进的讲述片段。每一步有明确意义；前进先显示后续片段，再换页，后退可回到前一步。打印时全部显示。
- SVG `[data-draw]`：真实路径描线，长短按实际路径长度计算。不要令图表坐标、单位和来源一起消失。
- `[data-count]`：只对已知的最终数值进行展示动画；终值、单位、精度来自数据，不随机产生。财务、医学或小样本等需要精确阅读的数值可直接显示。
- `.ambient`：装饰循环，只在当前活动页运行。SVG 使用本地坐标变换，不靠重复 DOM ID 或远端滤镜。
- `[data-kind="cover|content|chapter"]`：场景类型与视觉风格分开。章节页可以更有仪式感，正文页优先阅读。
- `#stage[data-motion="reduced"]` / `data-reduced-motion="true"`：无位移、缩放、旋转或循环；自动进场与装饰立即显示终态；手动 data-step 仍由用户推进。必要时只保留≤150ms 的淡入。
- `#stage[data-paused="true"]`、`body.document-hidden`：目录/讲稿打开或文档后台时暂停装饰。离开当前页后停止该页动画。

## 可打断与可恢复

把当前页、当前片段、过渡令牌与动画句柄放在一个状态来源中。每次导航先取消旧动画和延时，再建立新状态。快速连续按键后只能有一个当前页，没有残留遮罩、透明正文、重复页码或锁死按钮。返回页面应还原可预测的片段状态；不能因为用户中途反向操作就停在半张纸或半条曲线上。

目录、讲稿和全屏是用户控制功能：打开覆盖层时暂停背景动作，关闭后恢复原焦点；键盘焦点不能落入隐藏页。输入框、按钮或编辑内容中的键盘输入不应被当成翻页。触摸与鼠标入口要映射到同一导航状态。

## 动效安全与性能

- 不使用频闪、快速高对比明暗切换或全屏持续旋转。避免持续的强视差与大幅缩放。
- 优先 `transform`、`opacity` 和少量 SVG 路径动画。模糊、复杂滤镜和大面积动态渐变需要实机验证，不能仅凭静态截图判断顺畅。
- 每页通常至多一个背景循环场；静止页不应持续占用动画帧。复杂图表进入后停止绘制。
- 监听系统 `prefers-reduced-motion`，同时保留可见的“减少运动”入口。这个模式下内容、导航、数据和结论必须完整。
- PDF 是静态交付：冻结装饰、显现所有片段、移除舞台缩放、禁用动画，保留水印和页码。不要把隐藏片段或动画中间帧导出成空白。

## 必须观察的验收动作

不要以“CSS 存在 keyframes”作为动效通过的证据。打开最终 HTML，实际执行以下动作：

1. 在封面、普通页、章节页各观察一次进入/离开，记录实际发生的运动与结束状态；若只审阅了截图，应明确动效尚未验证。
2. 连续快速前进 5 次再后退 3 次；待结束后检查只有一页可交互，结论和页码与当前页一致。
3. 推进一页所有片段，再打开目录跳转并返回，检查片段状态、跳转目标和焦点恢复。
4. 切换减少运动，并以系统减少运动偏好再打开一次；确认动画不再产生位移/循环，内容仍完整。
5. 切换到后台或打开讲稿，确认环境动画暂停；关闭后仅活动页恢复。
6. 调整窗口到常见投屏比例与较小笔记本视口；标题、正文、速览和底部按钮不碰撞。必要时调整内容布局，不能仅把整页字体压到难读。
7. 导出 PDF 后检查页数与 HTML 一致，并渲染封面、含片段的数据页、深色章节页与末页。按内容密度扩展抽检，发现问题后修正并重新导出。

验收记录只写实测结果：文件、浏览器/环境、覆盖页面、动作和未覆盖项。不要承诺所有设备绝对流畅，也不要把一次空白页面打开成功当作离线可用。
