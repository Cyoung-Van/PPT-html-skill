# 六种视觉系统

样式代码是可运行起点，不是把所有内容套进同一版式。`assets/themes.css` 定义排版、色彩、构图与材质；`assets/decor.json` 提供无需网络的原生 SVG 装饰。选择一个主系统，按内容写场景，再用该系统完成细节。

## 选择与字体

| style 值 | 使用场景 | 首要识别特征 | 默认运动方向 |
|---|---|---|---|
| `swiss` | 研究、工程答辩、报告、理性品牌 | 非对称网格、大字级、细线、单一强调色 | 精确水平切换、依论述顺序显现 |
| `art-nouveau` | 艺术、香氛、文学、神秘感品牌；潮汐概念 | 植物线条、有机边界、衬线字体、柔和节律 | 曲线生长、缓慢起伏、沿弧线入场 |
| `art-deco` | 精品品牌、酒店、作品集、仪式性发布 | 对称轴、几何放射、阶梯形边框、金属细线 | 中央展开、对称揭幕、分层登场 |
| `memphis` | 创意工作室、青年活动、趣味产品 | 撞色、几何拼贴、粗细反差、错位节奏 | 短促错拍、轻微弹性、局部转动 |
| `skeuomorphic` | 航空仪表、设备操作、工程演示 | 一个完整控制台、材质与厚度、刻度与操作反馈 | 开机建立、机械位移、数值到位 |
| `psychedelic` | 音乐、实验艺术、短片展示 | 流动轮廓、展示文字、强色彩、光学图案 | 缓慢形变、景深变化、柔和漂移 |

字体栈只是降级方案，不保证换电脑后字形一致。若视觉依赖特定字形，找本地或合法可嵌入的字体，核实所用中英文、符号和数字的字形覆盖，再嵌入子集。不要把普通宋体宣称为瘦金体，也不要给长段正文使用难读的装饰字。统一正文与导航的可读字体，展示字体仅用于标题、引文和少量强调。

## Swiss / 瑞士风格

- 色板：冷白 `#f1f5f9`、深墨蓝 `#0a1a2e`、强调蓝 `#1f5fd6`。可换成另一种单一强调色，但保留黑白层级和间距秩序。
- 构图：左对齐、12 栏思维、明确基线；标题可以占八至九栏，右侧保留独立编号、照片或一句引文。装饰只承担分隔、定位、强调。
- 三种起点：① 大标题 + 一张横幅图的封面；② 左图右解释的实验/产品页；③ 一条共用基线上的指标或比较表。章节页使用超大编号或单条色面，避免继续复制正文页。
- 动效：章节转场沿水平轴推进；正文按“问题 → 证据 → 结论”依次进入；表格按需要解释的行显示。不要给每个词单独飞入。
- 保留：读者能一眼定位标题、数据和结论；同类数字对齐；数据图的尺度与单位稳定。
- 避免：全页居中、霓虹渐变、无意义装饰、把科研证据做成一堆按钮式卡片。

## Art Nouveau / 新艺术风格

- 色板：羊皮纸 `#f3eddf`、深苔绿 `#193a34`、植物绿 `#487968`、旧铜 `#a47839`。潮汐主题可引入低饱和海蓝，仍保留纸色阅读面。
- 构图：以一条连续主曲线组织视线，植物枝叶沿四周或图片轮廓延展。中部正文必须稳定；有机的是边界、连接与留白，不是正文基线。
- 三种起点：① 中央诗性标题 + 两侧生长的植物曲线；② 拱形照片/瓶身图 + 不对称短文；③ 一条潮汐路径串联三段叙事，每次只点亮当前段。文学引文可以用宽松衬线排版，证据表格仍用清晰直线结构。
- 动效：开场先描出主茎，再出现标题、图片、文字；潮线以 16–24 秒缓慢起伏。切页采用轻微纵向位移或弧向舒展，而非强弹跳。
- 保留：装饰与故事的语义联系，完整品牌标识比例，留白中的呼吸感。
- 避免：到处添加花朵、把表格画成不规则形状、文字沿曲线排到无法阅读、用高频滤镜制造“水感”。

## Art Deco / 装饰艺术

- 色板：深蓝绿 `#132127`、象牙白 `#f3e8d3`、哑金 `#dfb967`，以细线形成金属感。金色不能成为全页正文色。
- 构图：封面和章节页建立中央对称轴；放射纹样指向主题，阶梯边框界定舞台。内容页可用双栏，保持左右等重，细线区分层级。
- 三种起点：① 对称舞台封面，标题先露出、边框合拢；② 中央主物件 + 左右功能/价值对照；③ 细金线分隔的里程碑或作品编目，逐层揭示。
- 动效：线框 400–600ms 建立；主体 550–750ms 入场；左右信息按对称对进入。结束状态必须利落，不能持续闪亮。
- 保留：对称、精密间距、几何重复、材质克制。展示字可宽字距，但中文不宜被机械拉成疏散单字。
- 避免：用普通黑金卡片替代构图；全屏粒子；强烈反光扫过正文；把 Art Deco 与 Swiss 当作同一网格换皮。

## Memphis / 孟菲斯

- 色板：奶白 `#fff7e9`、深紫墨 `#211c33`、莓红 `#cc2857`、青绿 `#147f85`、柠檬黄 `#f9d74c`。高饱和色用于大块形状与标题标签，正文始终处在足够安静的底色上。
- 构图：保留共同网格后做可控错位；一页一个主形状群；几何拼贴以方向和重心牵引视线。卡片式内容只在真正并列的对象中使用。
- 三种起点：① 粗标题 + 偏置几何形的活动封面；② 三个不等高的创意提案，出现顺序 1→3→2；③ 大照片/作品拼贴 + 色块编号，讲完一件再进入下一件。
- 动效：350–500ms 短位移，轻微回弹一次；80–120ms 错拍；只有一两个装饰片段有小幅循环。正文和导航不摆动。
- 保留：可辨的操作入口、深色正文、明确阅读顺序。错位必须是被设计的偏移，不是未对齐。
- 避免：每个元素都旋转；密集波点铺在正文后；无限弹跳；让颜色代替信息层级。

## Skeuomorphism / 拟物主义

- 色板：石墨 `#202c32`、金属灰蓝 `#263b42`、夜光青绿 `#8ce2c2`、警示琥珀 `#f2ba70`。材料由少量明暗边界、内凹读数窗与固定光源共同建立。
- 构图：围绕一个可解释的真实物件组织内容，如控制台、仪表盘、检修台、飞行检查卡。先决定仪表、读数、控制器之间的空间关系，再决定阴影。
- 三种起点：① 控制台总览，按电源→指示→读数的顺序建立；② 仪表/刻度 + 可改变的参数 + 输出读数；③ 设备剖视/流程图 + 纸质检查清单。`.readout` 可直接承载数值，但只有真实数据才显示单位与精度。
- 动效：按钮压下 80–120ms，释放 120–180ms；指针或滑块 400–800ms 到位，最多一次阻尼收敛；标签和单位从始至终可见。
- 保留：统一光源、可操作对象的反馈、真实量纲、状态变化的解释。没有真实设备连接时明确标记“交互示意/模拟”，不能伪装遥测。
- 避免：普通网格卡片加阴影就称拟物；不停扫描的假仪表；凭空生成数值；把装饰旋钮做成看似能操作却无反馈的入口。

## Psychedelic / 迷幻风格

- 色板：深紫 `#23153a`、奶油白 `#fff2d8`、桃金 `#f9bc69`、粉紫 `#ef8ab5`。色彩运动只在外围的装饰场内发生。
- 构图：展示文字可有流动轮廓、伸展或轮廓叠影，但正文与导航建立稳定的矩形阅读区。把一页设计成一张有呼吸的演出海报，而不是整个屏幕不断旋转。
- 三种起点：① 大标题与慢速同心曲线的音乐/艺术封面；② 固定视频框 + 周围流动色场；③ 稳定的中央引文/作品说明 + 边缘光学图案。数据页减少装饰密度，不扭曲坐标与文字。
- 动效：650–900ms 柔和变形/景深过渡；背景周期 18–30 秒，位移通常不超过 2% 画布；只对短标题或装饰使用波形，正文进入后保持静止。
- 保留：静止区、可暂停运动、清楚的当前页与操作入口；减少运动模式下应仍是一份完整的设计。
- 避免：频闪、快速黑白反转、全屏旋转/缩放、正文扭曲、把音频自动播放当作沉浸的必要条件。

## 组合规则

默认一个主风格。若用户要求混合，明确哪个风格控制版式、哪个只贡献字体或装饰；同一套导航与数据标注保持统一。动效由选定系统和场景语义决定，不把全部风格随机混在一页。预览应至少覆盖封面、密集内容和章节转场，不能只给一张静态封面就声称风格与动效完成。

## 已实现的字体与场景起点

| 风格 | 展示字体 | 构图起点 |
|---|---|---|
| 瑞士 | Inter + Noto Sans SC | 非对称大字、独立编号栏、对齐数据清单 |
| 新艺术 | 霞鹜新致宋 + Cormorant Garamond Italic | 植物图版与文字对页、竖向叙事、拱形节律 |
| 装饰艺术 | 站酷庆科黄油体 + Poiret One | 几何中轴舞台、阶梯展开、成对细线 |
| 孟菲斯 | 站酷快乐体 + Lilita One | 错位文字海报、偏置色纸、贴纸式数值 |
| 拟物 | Noto Sans SC + Share Tech Mono | 真实空间关系的控制台、模拟仪表、纸质检查单、内凹读数 |
| 迷幻 | 马善政毛笔楷书 + Shrikhand | 中文书写轮廓与膨胀拉丁字、流动海报、稳定阅读岛 |

这是中文场景的风格适配，不将某一字体宣称为历史流派的唯一标准。展示字体用于标题与短标签，连续正文保持清晰。字体原文件与许可在 assets/fonts；构建器按当前内容内联子集。六套模板必须同时检查开场、过程、数据和收束页，不能仅用不同封面掩盖相同正文骨架。
